# 简单盒子 · Simple Box

> 一个面向 SillyTavern 的**轻量实用工具箱**，专注解决「长对话场景下的视图清理 + 剧情归档」这两件最日常的烦恼。

---

## 📜 功能一：隐藏楼层

把你不想看到的历史消息从聊天界面里「收起来」，不破坏任何上下文。

- **两种隐藏模式**
  - **A · 视觉 + 指令隐藏**：前端折叠 + AI 也看不到
  - **B · 仅指令隐藏**：前端依旧显示，但 AI 上下文已过滤

适合：压缩冗长前文、清理调试废话楼、保留视觉简洁性。

## 📜 功能二：总结

针对长篇 RP / 小说式对话设计的**剧情归档功能**。

### 🎯 核心能力

- **楼层范围总结**：指定起止楼层，或留空总结全部
- **双键驱动**
  - **开始总结**：调用你配置的提示词让 AI 归档
  - **压缩总结**：对已有总结条目做二次精炼压缩，越长的故事越需要
- **预览后写入**：AI 生成结果先在预览区显示，满意再落库

## 📜 功能三：档案压缩

针对**多个已归档的世界书条目**做二次合并精炼，专为长线连载、档案爆炸的场景设计。把零散的「前情概要 1 / 2 / 3 ...」喂给 AI，让它输出一份高密度的合并档案。

### 🎯 核心能力

- **跨世界书选条目**：从任意世界书勾选已存在的条目作为压缩素材
- **拖动排序**：拖动 <i>≡</i> 调整条目顺序，决定它们以何种时序作为「模拟历史」喂给 AI
- **临时屏蔽聊天历史**：生成期间自动隐藏当前所有楼层，让 AI 只看到你选中的条目内容；生成结束自动恢复
- **不冲突保护**：只恢复自己临时隐藏的楼层，「隐藏楼层」「总结」模块原本隐藏的楼层不受影响
- **继续按钮**：长输出可让 AI 接力补全，等同酒馆原生 `继续`按键

### 📚 内置总结模板

开箱即用，随版本持续更新：

| 模板 | 用途 |
|------|------|
| **Janus-灵魂典藏馆** | 面向多角色档案化存档，结构化记录人生履历、人物关系、组织归属、重要物品、未解之谜 |
| **打工喵** | 轻量阶段归档，聚焦关键冲突、决策、环境变化，含「待完成事件 / 重要物品 / 角色成长」三段式复盘 |

### 🔧 静默注入

- 提示词与触发文本**在后台静默注入**，玩家侧聊天界面完全不会看到污染
- 生成结束自动清理，不残留
- 统一使用 **User 身份**注入，指令独立成条、不污染已有提示词

### 📖 世界书自动归档

- **自动检测角色绑定的世界书**，一键填充
- 可指定任意世界书 + 条目名，不存在自动创建
- **覆盖 / 追加**双模式可选
- **自动清理思维链标签**：`<thinking>` / `<think>` / 自定义标签，写入前自动剥离
