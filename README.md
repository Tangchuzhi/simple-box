# 简单盒子 · Simple Box

> 一个面向 SillyTavern 的**轻量实用工具箱**，专注解决「长对话场景下的视图清理 + 剧情归档」这两件最日常的烦恼。

目前内置两大功能：**隐藏楼层** 与 **总结**。零配置开箱即用，界面风格与 SillyTavern 原生主题保持一致。

---

## ✨ 功能一：隐藏楼层

把你不想看到的历史消息从聊天界面里「收起来」，不破坏任何上下文。

- **两种隐藏模式**
  - **A · 视觉 + 指令隐藏**：前端折叠 + AI 也看不到
  - **B · 仅指令隐藏**：前端依旧显示，但 AI 上下文已过滤
- **精确楼层范围**：输入起止楼层一键隐藏/显示
- **一键恢复全部**：不小心隐多了？一键显示全部
- **楼层 0 = 开场白**，楼层 1 起为正文消息

适合：压缩冗长前文、清理调试废话楼、保留视觉简洁性。

## 📜 功能二：总结

针对长篇 RP / 小说式对话设计的**剧情归档神器**。

### 🎯 核心能力

- **楼层范围总结**：指定起止楼层，或留空总结全部
- **双键驱动**
  - **开始总结**：调用你配置的提示词让 AI 归档
  - **压缩总结**：对已有总结条目做二次精炼压缩，越长的故事越需要
- **预览后写入**：AI 生成结果先在预览区显示，满意再落库
- **一键重 ROLL**：不满意？同一次配置直接再生成一次

### 📚 内置高质量总结模板

开箱即用，随版本持续更新：

| 模板 | 用途 |
|------|------|
| **Janus-灵魂典藏馆** | 面向多角色档案化存档，结构化记录人生履历、人物关系、组织归属、重要物品、未解之谜 |
| **打工喵** | 轻量阶段归档，聚焦关键冲突、决策、环境变化，含「待完成事件 / 重要物品 / 角色成长」三段式复盘 |

> 💡 内置模板随插件版本统一更新；想自己改？另存新名字即可，互不打架（保存时禁止与内置同名）。

### 🔧 静默注入 + 多身份启动

- 提示词与触发文本**在后台静默注入**，玩家侧聊天界面完全不会看到污染
- 生成结束自动清理，不残留
- 启动身份支持：🤖 **AI 助手** / ⚙️ **System**

### 📖 世界书自动归档

- **自动检测角色绑定的世界书**，一键填充
- 可指定任意世界书 + 条目名，不存在自动创建
- **覆盖 / 追加**双模式可选
- **自动清理思维链标签**：`<thinking>` / `<think>` / 自定义标签，写入前自动剥离
- **写入后自动隐藏原楼层**（可关），帮你主动减负上下文

### ♻️ 压缩总结（高级用法）

当世界书里的总结条目本身变得过长，点「压缩总结」让 AI 对现有条目做二次精炼，确认预览后**强制覆盖原条目**。适合连载数百楼的超长剧情。

## 🔄 版本检查与自动刷新

- 插件面板顶部会显示当前版本号
- 启动时自动与 **GitHub 最新版本**对比
- 有新版 → 显示 `v1.0.0 → v1.1.0 [待更新]` 橙色提醒
- 在 SillyTavern 原生扩展管理面板点击更新后，插件会**自动检测并刷新界面**，无需手动 F5

## 📦 安装

### 方式一（推荐）：通过 SillyTavern 扩展管理器安装

1. 打开 SillyTavern → **扩展 (Extensions)** → **Install extension from URL**
2. 粘贴本仓库 Git 地址
3. 安装完成，在 **扩展设置** 中找到 **简单盒子**

### 方式二：手动安装

将整个 `simple-box` 文件夹放入：

```
SillyTavern/data/<用户名>/extensions/
```

重启 SillyTavern 即可。

## 🚀 快速上手

### 想隐藏旧楼层？

1. 打开 **简单盒子 → 隐藏楼层** 选项卡
2. 选择模式（A：彻底隐藏 / B：仅给 AI 看不见）
3. 输入起止楼层 → 点 **隐藏楼层**

### 想给当前故事做一次归档？

1. 打开 **简单盒子 → 总结** 选项卡
2. 从下拉菜单选择一个内置模板（如「打工喵」）
3. 可选：限定总结楼层范围
4. 点 **开始总结**
5. AI 生成完毕后，在下方预览区查看
6. 满意？点 **确认写入** 存进世界书；不满意？点 **重 ROLL**

## 🧭 设计理念

- **零侵入**：所有注入静默、自动清理，不在聊天界面留痕
- **可追溯**：总结必须预览确认后才会落库，宁慢不错
- **尊重用户**：内置模板由作者维护更新，但你的自定义预设永不丢失
- **主题友好**：使用 SillyTavern 原生 CSS 变量，无论你用什么主题都协调
